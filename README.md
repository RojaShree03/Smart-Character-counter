# Smart Character Counter – Text Utility Website

Smart Character Counter is a responsive text utility website built using **HTML, CSS, and JavaScript**. The project is designed to provide a simple, clean, and user-friendly interface for counting characters and words while working with text.

The website demonstrates the use of **JavaScript DOM manipulation, event handling, string methods, LocalStorage, and Clipboard API** to create a real-time text utility application.

## Features

- Responsive design for mobile, tablet, and desktop screens
- Real-time character counting
- Real-time word counting
- Custom character limit
- Remaining character display
- Character limit warning
- Clear text button
- Copy text button
- Text transformation tools:
- UPPERCASE conversion
- lowercase conversion
- Title Case conversion
- Sentence Case conversion
- Trim Spaces
- Remove Blank Lines
- Reverse Text
- Duplicate word detection
- Copy Text option
- Copy Statistics option
- Automatic text saving using LocalStorage
- Character limit prevents further typing after reaching the limit
- Responsive text utility layout
- Clean and user-friendly interface

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **Browser LocalStorage**
- **Clipboard API**
- **Responsive CSS**

## Responsive Design

Smart Character Counter is designed to work across different screen sizes.

- **Mobile:** Single-column layout with responsive buttons and controls
- **Tablet:** Flexible content layout with properly arranged text tools
- **Desktop:** Spacious text editor layout with organized text utility sections

CSS media queries are used to adapt the layout according to the screen size.
